Zentia AI Documentation

1. Getting Started

Zentia AI allows you to deploy autonomous sales agents on Telegram. To get started, you need a Telegram Bot Token and an AI API Key.

Step 1: Get a Telegram Bot Token

1. Open @BotFather in Telegram.

2. Send /newbot and follow the instructions.

3. Copy the HTTP API token provided.

Step 2: Setup API Keys

Go to the Settings section in your Zentia Dashboard and provide either an OpenRouter API key or a Gemini API key. This key will be used to generate AI responses.

2. Agent Configuration

When creating an agent, you can configure the following:

  • Name: The display name of your agent in the dashboard.
  • Bot Token: The token from @BotFather.
  • Model: Choose between various Gemini models (Flash for speed, Pro for reasoning).
  • System Prompt: Define the agent's goal, target audience, tone, and rules.

3. Knowledge Base

You can upload PDF or text files to your agent's knowledge base. The agent will use this information to provide accurate answers about your specific product or service.

4. Analytics

The analytics tab shows token usage, unique user counts, and estimated costs. You can filter by agent or by model.

5. Inbox & Lead Management

All interactions are captured in the Inbox. You can view full transcripts, update lead status (Interested, Qualified, etc.), and manually intervene in conversations if necessary.

6. API Integrations

Zentia supports Webhooks and Google Sheets. You can configure a webhook URL to receive lead data in real-time or sync leads to a Google Sheet automatically.
